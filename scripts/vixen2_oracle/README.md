This records the unchanged upstream `Vixen2xSequenceImportSM.cs` using lightweight effect and sequence services. `generate.py /path/to/local/dotnet` regenerates 150 deterministic channel cases in the Rust fixture. The project links the upstream file directly; no upstream file is changed. Restore uses an empty local feed and needs an already installed .NET 10 SDK. The fixture exercises threshold values, monotonic ramps, repeated intensities, color changes and channel close.
