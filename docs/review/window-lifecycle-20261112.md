# Four standalone window lifetime fixes — 2026-11-12

The four audited presenters have the same reproducible ARC failure as Element Mapper: closing a standalone window calls legacy AppKit release-on-close, followed by an invalid release during the autorelease-pool drain. The proposed change sets `isReleasedWhenClosed = false` immediately after each Swift-created window. The original parented sheet paths continue to close and release correctly.

The patch is prepared but **not applied by this review**: `target/window-lifecycle-followup/release-on-close.patch`. It changes four assignments in three source files: Song Inventory, Export Sequence, and both Vixen2 presenters. It adds no retention cycle, controller, callback change, or global window policy.
