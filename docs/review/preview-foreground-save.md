The final private debug candidate `9c0fc1ed41611feb0281d3a5f2c6d163a3640bb3d6858547edb894ec04130cad`, whose seven listed source/runner hashes matched the current files before launch, passes all 84 strict actions in `target/preview-foreground-newitem-acceptance/result.json`. The actual Preview window owns key/main during its shortcuts; the sequence owns both during its own operations. `inFront` follows false → false → true → false across the four observations. Preview Save now persists one grouped shape, then two ungrouped shapes, while both windows remain open; each write changes ModuleStore and leaves the sequence file byte-identical. Both windows' exact Undo/Redo histories stay isolated. `focus-verification.json` independently checks the retained identities, nine Preview key events, actual file-hash changes and live checkpoints. All actions and the app exit succeed; the guard observes continuous ownership and restores Chrome after the test process exits.
