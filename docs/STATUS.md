# Port status

This is an experimental macOS port, not an official Vixen release. The current goal is reliable use on the maintainer’s Mac.

## Remaining usability work

- Validate the latest candidate through normal app launch and representative real-show workflows: open, edit, save, reopen, preview, playback and export.
- Fix crashes, data loss, broken workflows, and noticeable responsiveness, memory or audio synchronization problems.
- Promote the accepted build with a rollback copy and record remaining limitations.

Imperceptible audio/rendering differences are acceptable. Exact Windows parity, additional OS-version certification, Intel support and notarized distribution are not completion requirements for this milestone. Always use a private copy of a show during testing.

The latest local workspace test checkpoint was 3,549 passed, zero failed and 10 ignored. No full-port completion is claimed. Private execution receipts and machine-specific session notes remain outside this public repository. Historical verification documents refer to those local receipts and may describe earlier builds or stricter parity goals.

The public source snapshot retains the current app implementation, synthetic fixtures, test tools, specifications and license notices. Local paths have been normalized to examples; private show files, recordings, keys, network setup scripts and build products are excluded.
