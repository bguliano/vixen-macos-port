# Generated decoder fixtures

`colors.mov` and `quarter_turn.mov` are generated by `../make_assets.swift`.
`colors.avi` is a MPEG-4 Part2 AVI transcode of the same three-second colors movie,
created by the local FFmpeg9.0.2 codec audit. It contains synthetic red/green/blue
frames, no user media, and no audio. It can be regenerated with a development
FFmpeg build containing the MPEG-4 encoder and AVI muxer:

```sh
ffmpeg -i colors.mov -an -c:v mpeg4 -q:v 2 colors.avi
```

The checked-in AVI SHA256 is
`2448144002994bfc07960f53947fc4b6420524a10023e93554ad914a2d5e84c2`.
The production helper intentionally enables decoding and raw output rather than
the MPEG-4 encoder/AVI muxer, so fixture regeneration is separate from app use.
